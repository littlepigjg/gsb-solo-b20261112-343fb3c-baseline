# 素材包迁移说明

素材迁移包用于在两个独立部署的“光屿 · 图像工作室”之间搬运素材及其完整
处理血缘，不需要数据库或账号体系。整个过程只交换一个 ZIP 文件。

## 1. 导出

```bash
curl -X POST http://127.0.0.1:8765/api/bundles/export \
  -H "Content-Type: application/json" \
  -d '{"asset_ids": ["素材ID1", "素材ID2"]}'
```

- 请求体只接受 `asset_ids`，数组长度 1–24 且 ID 不可重复；重复 ID 会自动去重。
- 服务沿每个素材的 `parent_id` 自动补齐全部祖先。例如只选择一张第三代
  处理结果时，原图与中间副本都会被纳入包内。
- 补齐祖先后若总数超过 24 项，返回 400（`bundle_too_large`），请缩小选择范围。
- 响应 `data` 是一条导出记录，其中 `url` 指向
  `GET /api/exports/{id}/download`，与普通导出共用下载链路；下载文件名为
  `光屿_素材迁移包.zip`。

## 2. 包格式

ZIP 内只包含以下成员，任何其他成员都会在导入时被拒绝：

```text
manifest.json
images/<原ID>.png
```

`manifest.json`：

```json
{
  "version": 1,
  "selected": ["原ID"],
  "assets": [
    {
      "id": "32位小写十六进制ID",
      "name": "素材名称（支持中文）",
      "parent_id": null,
      "root_id": "根素材ID",
      "width": 384,
      "height": 320,
      "sha256": "包内 PNG 字节的 sha256 摘要",
      "file": "images/<原ID>.png",
      "steps": [{"operation": "color_invert", "params": {}}],
      "favorite": false,
      "tags": ["标签"]
    }
  ]
}
```

`assets` 按父先子后排列；`selected` 保留请求中的选择顺序。`sha256` 始终
针对包内实际 PNG 字节计算，导入时逐字节复核。

## 3. 导入

```bash
curl -X POST http://127.0.0.1:8765/api/bundles/import \
  -F "file=@光屿_素材迁移包.zip"
```

成功响应：

```json
{
  "ok": true,
  "data": {
    "mapping": {"旧ID": "新ID"},
    "selected": ["映射后的新ID"]
  }
}
```

- 每个素材都会获得新的 UUID，**不会覆盖**目标库中的任何现有资产；同一个包
  可以重复导入，每次生成独立副本。
- 父/根关系、名称、处理步骤、收藏状态和标签按映射完整恢复；PNG 字节、
  尺寸与 sha256 保持不变。
- `selected` 按导出时的选择顺序给出映射后的新 ID，便于调用方继续定位
  用户真正选中的素材。
- 原库中的素材在导出后不发生任何变化。

## 4. 限制与安全边界

| 项目 | 限制 |
| --- | --- |
| 单次选择 / 包内资产数 | 1–24 项（含自动补齐的祖先） |
| 上传体积 | 24 MiB |
| 解压展开总体积 | 64 MiB |
| 图片格式 | 仅 PNG，尺寸受系统像素边界约束 |
| 单个素材标签 | 最多 12 个，每个最长 30 字符 |
| 步骤数 | 最多 12 步 |

导入遵循“先完整校验、后统一写入”：

1. 校验 ZIP 成员集合：拒绝目录、重复成员、绝对路径、反斜杠、`..` 路径穿越、
   符号链接、非常规文件和任何未知文件。
2. 校验清单：版本必须为 1；字段集合、类型、ID 格式、标签与步骤结构逐项检查。
3. 校验图片：必须是可解码 PNG，实际尺寸与清单一致，sha256 与清单一致。
4. 校验血缘：所有 `parent_id`、`root_id` 必须指向包内素材，不允许环，
   根素材不能有父图，且 `root_id` 必须等于父链顶端。
5. 全部通过后才在同一把资产锁内按父先子后写入；中途若发生异常，已写入的
   JSON 记录和图片文件会被回滚清理，不会留下半成品。

校验失败统一返回 `{"ok": false, "error": {...}}`，HTTP 状态码为 400
（上传超限为 413），`details` 中给出涉及的成员名或素材 ID，便于排查。

## 5. 典型迁移流程

1. 在源工作室调用 `/api/bundles/export`，下载 ZIP。
2. 通过任意离线方式（U 盘、内网共享等）把 ZIP 传到目标机器；包内不含
   凭据或服务器路径，可安全搬运。
3. 在目标工作室调用 `/api/bundles/import` 上传。
4. 用响应中的 `mapping`/`selected` 对照新旧 ID；在素材库中即可看到恢复的
   名称、血缘历史、收藏与标签。
